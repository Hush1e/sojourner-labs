HOCKING COLLEGE CAREER NAVIGATOR · Teacher Class Summary

See what your class discovered

1. Make up a short class code, like HAWKS3 or NHS2PERIOD, and write it on the board.

2. Students type it in the "Class code" box before they start. At the end, each student gets a result code that looks like HAWKS3~ICR~cyber~tech, with a Copy button.

3. Collect the codes any way you like: a Google Form, a shared doc, the chat, or students reading them aloud. Paste them all below, one per line or mixed in with other text.

Nothing is uploaded or saved. Codes contain no names, only the interest code, top program, and top subject area.
